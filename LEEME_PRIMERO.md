# Paquete de implementación para Codex — GameHive

Contenido:

- `GAMEHIVE_MASTER_SPEC.md`: especificación maestra y criterios de aceptación.
- `AGENTS.md`: instrucciones de comportamiento persistentes para Codex.
- `BACKLOG.md`: tickets, prioridades, dependencias y gates de calidad.
- `PROMPT_INICIAL_CODEX.md`: prompt copiable para empezar la implementación.

## Procedimiento

1. Crear y abrir un **directorio NUEVO** del proyecto, distinto de `KingOwls/ProjectWebVideoGame`.
2. Copiar allí los cuatro `.md` principales y opcionalmente el documento maestro de GameHive (`.docx`) en `docs/reference/`.
3. Confirmar en el terminal que no existe un remoto Git apuntando al proyecto original.
4. Abrir Codex con ese directorio, copiar y enviar el contenido de `PROMPT_INICIAL_CODEX.md`.
5. El proyecto se implementa en etapas; tras G0 seguir G1–G6 con pruebas. No se espera que una única sesión complete todo de forma confiable.
6. Para instalar BMAD estable, Codex debe verificar requisitos/versiones y consultar https://docs.bmad-method.org/start/install-bmad/. Evitar inventar comandos de agentes.

No se incluyen claves, cuentas, despliegues ni código copiado del repositorio de referencia.
