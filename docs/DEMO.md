# Demo local G0

1. `npm ci && npm run build && npm run preview`.
2. Abrir Explorar: identificar el aviso de catálogo curado sin conexión.
3. Buscar Hades; abrir ficha; comprobar fuente oficial y ausencia de scores inventados.
4. Combinar género/plataforma/año; buscar texto inexistente; limpiar filtros; cambiar página.
5. Cambiar Sistema/Claro/Oscuro, refrescar y comprobar persistencia. Usar teclado y salto al contenido.
6. Abrir Vitrina UI para estados de ejemplo y spoiler oculto; activar movimiento reducido en navegador/SO.
7. Estado del proyecto explica que Auth y comunidad aún no están integrados; no ingresar credenciales allí.

Esta demo no demuestra los cinco flujos P0 finales. La evaluación final requiere cuatro cuentas reales y los escenarios de la especificación §15.
